# Правила для AI-агентов (manga-crawler)

## Миграции БД и снимок схемы

При добавлении или изменении любого файла в `backend/internal/storage/migrations/` сразу обновляй снимок схемы `backend/docs/schema.sql` командой `go run ./cmd/schemadump` из `backend/` (нужен запущенный контейнер `db`, миграции применяются при старте процессов; повторный запуск без изменений ничего не перезаписывает). Снимок — производный артефакт и должен соответствовать состоянию миграций, иначе справочник docs/schema.sql вводит в заблуждение, поэтому не редактируй его руками и коммить обновление в том же PR, что и миграцию.
